# ELDOSTORE — sitio público

Archivos publicados de la tienda **eldostore.com.ar**: la tienda (`index.html`), el panel
(`admin.html`), sus estilos y scripts, y las fichas para compartir de cada producto (`p/`).

Este repositorio es público y **solo** contiene lo que el sitio publica.
No subas acá inventarios, costos, respaldos, migraciones SQL, guías internas ni claves.
La clave de Supabase de `js/supabase-config.js` e `index.html` es la publicable (pública por
diseño); los datos están protegidos por las políticas de seguridad (RLS) de la base.
